# 打字问候本地预览

打开 `index.html` 可查看时间横幅、三句打字问候以及原有角色／title 区域。
SVG 来自 [DenverCoder1/readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg)，
四个缓存文件分别覆盖电脑／手机和浅色／深色模式。

三句话按顺序出现并保留，读完后一起重置。手机将长句分行显示。
该页面使用本次生成的时段快照，缓存动画可离线播放。

实际 README 的 SVG 地址由 `scripts/update_banner.py` 与横幅同时更新，
继续使用已有纽约时间分段；详细说明见 `docs/banner.md`。
